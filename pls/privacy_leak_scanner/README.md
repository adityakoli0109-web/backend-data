# Privacy Leak Scanner

Web-based PII detector for authorized files. Select one file in the browser and scan it.

## Supported formats
- PDF (including scanned/image PDFs through OCR)
- PNG, JPG/JPEG, BMP, TIFF/TIF, WEBP (OCR)
- CSV
- XLSX/XLSM
- DOCX
- PPTX
- TXT, MD, LOG
- JSON, XML, HTML/HTM, YAML/YML

## PII signals
- Email
- Indian phone number
- Aadhaar-like 12-digit number
- PAN-like number
- Date of birth/date pattern

Detected values are masked in the results. Use the scanner only on files you are authorized to analyze.
